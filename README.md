## The emoji

# 🤗

One emoji, and nothing else: U+1F917 HUGGING FACE.

## Why this one

The judge is a stranger glancing at a phone screen. Open arms offering a
hug is the warmest friendly gesture a stranger can send — kind and
welcoming with no context needed, understood the same way by anyone of any
age or background, with no irony or in-joke that could land wrong. It is
not the first smiley that comes to mind (🙂 / 😊 / 😄), so it feels picked
for the moment while staying instantly readable. And a friendly hug
gesture carries no intimacy, sarcasm or flirtation — unlike a heart or a
face with hearts, which can read oddly coming from someone unknown.

## How to run

```sh
python3 main.py
```

Writes exactly one emoji (4 bytes, no trailing newline) to
`/output/entry.txt`. Python standard library only; deterministic — every
run produces byte-identical output.
